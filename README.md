# Shroom & Gloom 辅助面板

游戏 **Shroom and Gloom** 的悬浮辅助面板。只读游戏内存，**不修改任何游戏文件**，随时关掉不影响存档。

## 下载

1. 打开 **[Releases 下载页](https://github.com/XIZI-2007/shroom-trainer/releases/latest)**
2. 下载最新版的 `ShroomTrainer.exe`

> **不需要装 Python，不需要管理员权限。** 就一个 exe（约 80 MB），双击即用。

## 使用

1. 启动游戏 **Shroom and Gloom**
2. 双击 `ShroomTrainer.exe`
3. 点面板上的 **「连接游戏」**
4. 拨动需要的开关

面板默认浮在游戏上方，**点击它不会抢走游戏焦点**，可以边玩边看。

## 功能

| 开关 | 作用 | 快捷键 |
|---|---|---|
| 无敌免疫伤害 | 免疫一切伤害来源，血量不再下降 | `F1` |
| 使用卡牌不消耗精力 | 打出卡牌零消耗，费用显示为 0 | `F2` |
| 窗口置顶 | 面板浮在游戏之上，不被窗口遮挡 | `F4` |
| 牌库顺序 | 看当前是营地牌库还是战斗牌库、剩余多少张、下一张是什么 | |
| 打法建议 | 按手牌算出最优出牌顺序，并标出每一步打谁、那个目标当前多少血 | |

`PageUp` / `PageDown` 滚动面板内容。

### 运行状态页

点标题左边的圆盘按钮滑出，里面有三张卡：

- **运行状态** —— 连接状态、PID、血量、精力、格挡、挂钩健康度
- **遗忘手牌** —— 从手牌里删掉指定卡（二次确认）
- **控制台** —— 荧光特效三档（彩色 / 单色 / 关闭）

### 打法建议怎么读

卡面每格两行：

```
2  猛击  [1]        <- 第 2 步、牌名、费用
→ ① 6/10            <- 打「从左到右第 1 只」敌人，它当前 6 / 上限 10 血
```

敌人**没有名字**（游戏没给），所以按面板上从左到右的顺序编号 ①②③。
如果有牌是打全体的，那一格显示 `→ 全体`。

> 手牌 6 张以内走精确穷举，超过则用贪心近似 —— 卡面会标注是哪一种。

## 常见问题

**连接不上？**
先确认游戏已经进到关卡里（在主菜单连不上是正常的），再点「连接游戏」。
还不行的话，把面板关掉重开一次。

**杀毒软件报警 / 文件被删？**
正常现象。面板用 Frida 往游戏进程里注入只读读取代码，这个行为跟外挂特征重名，
容易被误报。**需要把 `ShroomTrainer.exe` 加进杀毒软件白名单**。

**`重建挂钩` / 挂钩失败提示？**
游戏更新过就会这样 —— 内存地址变了。等新版本。

**游戏更新了还能用吗？**
不一定。游戏一更新，内存偏移就可能变，需要重新做一次适配。关注 [Releases](https://github.com/XIZI-2007/shroom-trainer/releases) 有没有新版本。

**设置存哪？**
Windows 注册表 `HKCU\Software\XIZI\ShroomTrainer`。**不会在 exe 旁边生成任何文件。**

**能开两个吗？**
不能，单实例。已经开着一个时会提示你。

## 自己编译

需要 Python 3.13 + 依赖（PyQt6、frida、numpy 等）。

```bash
pip install PyQt6 frida numpy UnityPy
```

改完代码后双击 `重新打包.bat` 即可产出 `dist/ShroomTrainer.exe`。

源码结构：

| 目录 | 内容 |
|---|---|
| `src/` | 面板主程序（`trainer_gui.py`）、内存桥（`trainer_core.py`）、注入脚本（`agent.js`）、打法推演（`battle_planner.py`）、意图理解（`intent_reader.py`） |
| `src/*.json` | 离线生成的数据表（卡牌意图、状态效果、术语词典、牌名汉化） |
| `tools/` | 数据生成器与自检脚本 |
